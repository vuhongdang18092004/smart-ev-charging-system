# Smart EV Charging System

A web and mobile system for searching, locating, and managing electric vehicle charging stations.

## Overview

This project aims to provide a platform that helps users find and view information about EV charging stations, while also supporting charging station management.

The project consists of three main applications:

* **Frontend** — Web application built with Next.js.
* **Mobile** — Cross-platform mobile application built with React Native.
* **Backend** — Backend system built with Java and Spring Boot.

## Technology Stack

### Frontend

* Next.js
* React
* TypeScript
* Tailwind CSS

### Mobile

* React Native
* TypeScript

### Backend

* Java
* Spring Boot
* PostgreSQL
